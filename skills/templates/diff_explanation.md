# 코드 변경 해설 (diff_explanation)

diff·브랜치·PR 등 코드 변경을 독자가 이해하도록 풀어 설명하는 문서. (작성용 — write-document. Quiz 기본 ON인 유일한 유형.)

## 섹션
- **요약** [필수] — 이 변경이 무엇을 하는가 한 문단.
- **Background** [필수] — 변경과 관련된 기존 시스템 설명. 주변 코드를 넓게 탐색해 쓴다. 독자의 사전 지식을 모르므로 초심자용 깊은 배경(이미 아는 독자는 건너뛸 수 있다고 표시)과 변경에 직결된 좁은 배경을 함께 담는다.
- **Intuition** [필수] — 변경의 핵심 직관. 전체 디테일이 아니라 본질을 설명한다. toy data를 쓴 구체 예시("설명용 예시" 라벨)와 그림·다이어그램을 적극 활용.
- **Code** [필수] — 변경 코드의 하이레벨 워크스루. 이해하기 쉬운 순서로 그룹핑·정렬한다.

## 작성 지침
- Quiz(UX 플로우에서 기본 ON)는 변경의 실질을 이해해야 풀 수 있는 중간 난이도 5문항 — 함정 문제 금지. HTML export면 클릭 시 정오·피드백을 보여주는 인터랙티브 객관식, MD면 `<details>` 접이식 Q&A.
- 소수의 다이어그램 패밀리를 정해 문서 전체에서 재사용한다(예: 단순화한 UI 스케치, 예시 데이터가 담긴 데이터 흐름/컴포넌트 다이어그램).
- ASCII 다이어그램 금지 — HTML export면 HTML 도형/표/리스트로, MD면 mermaid·표로 그린다.
- HTML export의 시각 골격(CSS 토큰·컴포넌트 카탈로그·퀴즈 JS)은 `../style/html-layout.md`를 원본으로 복사해 시작한다.
- 핵심 개념·정의·엣지 케이스는 callout으로 강조한다.
