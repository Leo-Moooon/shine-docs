# 이슈/백로그 티켓 (issue_ticket)

할 일을 정의하는 issue/backlog 티켓 본문. (작성용 — write-document)

## 섹션
- **요약** [필수] — 무엇을 왜 하는지 한 문단.
- **배경/문제** [필수] — 지금 무엇이 문제인가, 왜 지금인가.
- **할 일 (범위)** [필수] — 수행할 작업 목록.
- **완료 기준** [필수] — 검증 가능한 조건. "무엇을 보면 끝났다고 하는가".
- **범위 제외 (Out-of-Scope)** [필수] — 이번에 하지 않는 것(추적성 확보).
- **영향/의존성** [선택] — 다른 작업·팀·계약에 미치는 영향.
- **참고 자료** [선택] — 스펙 문서·관련 티켓·링크.
- **리스크/열린 질문** [선택] — 미검증 가정, 결정이 필요한 지점.
