# 가독성 리뷰어 체크리스트 (review-checklist)

가독성 리뷰어가 초안을 판정할 때 순회하는 질문 목록. 여기는 판정용 질문만 두고, 각 항목의
규칙 원문은 다른 곳이 단일 원본이다 — 문체·표기 축은 `writing-style.md`의 해당 절이,
내부 일관성과 실행가능성은 `../review-document/SKILL.md`가 갖는다. "아니오"가 하나라도
나오면 그 원문을 근거로 반려한다.

이 목록은 **문서 텍스트만으로 판정 가능한 축**만 담는다. 문서 밖 자료를 들고 대조해야 하는
축(사실성·참조 유효성·공란 규율)은 `verification-checklist.md`를 순회하는 검증 리뷰어의
몫이다. 가독성 리뷰어에게는 근거 원문을 주지 않는다 — 배경 지식을 쥐여주면 아래 "독자
적합성" 항목이 무력화되기 때문이다.

## 구조

- [ ] 본문이 최종 상태 기준으로 서술되어 있는가? 과정·시행착오 연대기가 본문 논리
      구조에 섞여 있지 않은가? (§1)
- [ ] 요약/개요가 "이 문서로 무엇을 알게 되는가"에 먼저 답하는가? 배경·일반론으로
      시작하지 않는가? (§3)
- [ ] 제목·헤딩에 핵심 키워드가 있고, 평서문이며, 같은 레벨끼리 문형이 통일되어
      있는가? (§4)
- [ ] 분할 신호(H4 이상, 독립 주제 2개 이상, 분량 규격 초과)가 떴는데 무시하고 단일
      산출물로 밀어붙이지 않았는가? 신호가 있으면 유형별 대응 제안이 이루어졌는가? (§11)

## 용어

- [ ] 독자가 모를 수 있는 개념이 첫 등장에서 한 문장으로 설명되는가? (§5)
- [ ] 같은 개념이 문서 안에서 한 용어로 일관되게 불리는가? (§5)
- [ ] 영문 약어가 첫 등장에서 풀어 쓰여 있는가? 공식 표기를 따르는가? (§5)

## 문장

- [ ] 수동형으로 쓸 이유가 없는 문장이 능동형으로 되어 있는가? 독자가 할 행동이
      독자 주어로 쓰였는가? (§6)
- [ ] "수행/진행/실시" 같은 군더더기 한자어와 명사 나열 없이 동사 중심인가? (§6)
- [ ] "앞서 설명했듯이" 류의 메타 담화가 없는가? (§6)
- [ ] 한 문장에 하나의 생각만 담겨 있는가? (§6)
- [ ] 근거가 있는 사실이 "~할 수도" 식 헤지 없이 조건·수치로 확정 서술되어 있는가?
      반대로, 확인 안 된 내용을 확정 서술하지는 않았는가? (§6)

## 표현·밀도

- [ ] bullet이 진짜 병렬 나열에만 쓰였고, 논리 전개는 산문인가? bullet 항목이 완결된
      문장인가? (§7)
- [ ] 금지 패턴(상투적 연결어, 과장 수식어, 화살표 체인, 3항목 강박, bold 남발,
      과도한 헤더, 장식 이모지)이 없는가? (§8)
- [ ] 문단이 2~4문장이고, 표에 설명·해석이 들어가 있지 않은가? (§9)
- [ ] 분량을 줄이면서 문장을 조각내지 않았는가 — 남긴 내용이 완결된 문장인가? (§10)

## 표기

- [ ] 한국어 본문에 한자·중국어 문자가 노출되지 않았는가? 원어 병기가 필요한
      고유명사·인용이라면 괄호 안 1회로 제한되어 있는가? (§12)
- [ ] 오탈자와 띄어쓰기 오류가 없는가? (§12)
- [ ] 같은 대상이 한글·영문으로 번갈아 불리지 않고 한 표기로 고정되어 있는가? (§12)

## 내부 일관성

문서 자기 자신과의 대조다. 외부 근거가 없어도 판정되며, 그래서 오탐이 거의 없다.

- [ ] 앞에서 한 주장과 뒤에서 한 주장이 서로 모순되지 않는가?
- [ ] 요약·개요의 수치가 본문·표의 수치와 일치하는가?
- [ ] 같은 대상이 문서 안에서 두 이름으로 불리지 않는가? (§5와 함께 본다)
- [ ] 목차·상호참조가 실제 섹션 구성과 맞는가?

## 독자 적합성

판정 기준은 "여섯 달 뒤의 본인이나 옆 팀 사람이 읽어도 성립하는가"다. 작성 당사자만 아는
맥락이 설명 없이 들어갔는지 본다.

- [ ] 조직 내부 은어·팀 관행이 설명 없이 쓰이지 않았는가?
- [ ] 티켓번호·사람 이름·시스템 이름이 무엇인지 밝히지 않은 채 등장하지 않는가?
- [ ] 코드 식별자가 어디에 있는 무엇인지 없이 던져지지 않았는가?
- [ ] "그 이슈", "지난번 그거" 같은 지시어로 대상을 넘기지 않았는가?

## 실행가능성 (티켓·PR류에만 적용)

`issue_ticket`, `bug_ticket`, `pull_request`에만 순회한다. `general`과 `diff_explanation`
에는 적용하지 않는다.

- [ ] 읽고 나서 무엇을 해야 하는지가 문서에서 나오는가?
- [ ] 버그 티켓이라면 재현 절차가 있는가? 없다면 공란 사유가 한 줄 남아 있는가?
- [ ] 완료를 무엇으로 판단할지(수용 기준·검증 방법)가 있는가?
